# 2 系统开发技术介绍

本系统的开发涉及多项主流技术，本章将对系统所采用的核心技术框架、数据库及相关工具进行逐一介绍，为后续系统设计与实现奠定技术基础。

## 2.1 Spring Boot框架

Spring Boot是由Pivotal团队基于Spring框架开发的全新应用开发框架，其核心设计理念是"约定优于配置"，旨在简化Spring应用的初始搭建和开发过程[9]。在Spring Boot出现之前，搭建一个Spring Web项目需要繁琐地配置web.xml、applicationContext.xml等大量XML文件，且各组件之间的版本兼容性问题频发。Spring Boot通过内置自动配置机制，将许多常见的配置操作内部整合，开发者仅需引入相应的Starter依赖即可自动完成配置，从而将开发者的精力集中于业务逻辑本身[10]。

Spring Boot的主要特性包括：内嵌Tomcat、Jetty等服务器，无需部署WAR文件即可独立运行；提供大量的Starter依赖包，简化Maven或Gradle构建配置；具备Actuator生产级监控功能；支持外部化配置，便于在不同环境间切换。本系统采用Spring Boot 2.7.18版本，其成熟稳定的特性为系统的高效开发和稳定运行提供了重要保障。

## 2.2 MyBatis-Plus

MyBatis-Plus是在MyBatis基础上进行增强的持久层框架，在不改变MyBatis原有功能的前提下提供了大量便捷特性，旨在简化开发、提高效率[8]。MyBatis-Plus内置了通用Mapper，封装了常见的CRUD操作，开发者无需编写重复的SQL语句即可完成基础的数据库操作；提供了强大的条件构造器（Wrapper），支持链式调用方式灵活构建查询条件；内置分页插件，只需简单配置即可实现物理分页；支持逻辑删除、自动填充（创建时间、更新时间等字段）、乐观锁等实用功能。

本系统充分利用MyBatis-Plus的上述特性，结合XML映射文件处理复杂的多表联查场景，在保持代码简洁的同时保证了数据访问层的灵活性与高效性。系统中的逻辑删除设计（deleted字段）、创建时间与更新时间的自动填充均依托MyBatis-Plus的内置机制实现，显著减少了重复代码量。

## 2.3 Vue 3框架

Vue是一套用于构建用户界面的渐进式JavaScript框架，其核心库专注于视图层，具有简洁、高效、灵活的特点[12]。Vue 3在Vue 2的基础上进行了全面重构，引入了Composition API（组合式API），使得逻辑复用更加灵活，代码组织更加清晰；采用基于Proxy的响应式系统，性能相比Vue 2有显著提升；支持Tree-shaking，打包体积更小；同时对TypeScript的支持更加友好。

Vue的组件化开发模式允许将页面拆分为独立可复用的组件，每个组件包含自己的模板、逻辑和样式，既提高了代码的可复用性，又便于团队协作开发。本系统前端采用Vue 3结合Vite构建工具，搭配Element Plus组件库和ECharts图表库，实现了功能完善、交互友好的管理界面。

## 2.4 MySQL数据库

MySQL是由Oracle公司维护的开源关系型数据库管理系统，以其卓越的性能、出色的稳定性和丰富的功能特性，成为Web应用开发领域最广泛使用的数据库之一[7]。MySQL支持标准SQL语言，提供完善的事务处理机制，保证数据的一致性和完整性；支持多种存储引擎，其中InnoDB引擎提供行级锁、外键约束和崩溃恢复能力，是绝大多数业务场景的首选；具备良好的跨平台特性，可在Windows、Linux、macOS等主流操作系统上运行；支持高并发访问和大规模数据存储，能够满足企业级应用的性能需求[8]。

MySQL还具备强大的权限管理和数据安全机制，支持用户级别的访问控制，有效防止未经授权的数据访问；提供完善的数据备份与恢复功能，保障数据安全可靠。本系统采用MySQL 8.0版本，共设计28张业务数据表，涵盖用户管理、房产管理、费用管理、服务管理等各业务领域。通过合理的索引设计和表结构规范化，保证了系统数据访问的高效性和数据存储的规范性。

## 2.5 Redis缓存

Redis（Remote Dictionary Server）是一款基于内存的高性能键值存储数据库，目前已成为最流行的开源缓存解决方案之一。Redis支持字符串、哈希、列表、集合、有序集合等多种数据结构，具备极高的读写性能，单机每秒可处理十万级别的读写请求，常用于缓存、会话管理、消息队列等场景[11]。

Redis支持数据持久化（RDB和AOF两种方式），在服务重启后能够恢复数据；支持设置键的过期时间，非常适合临时数据的存储管理；提供原子性操作，保证并发场景下的数据一致性。本系统使用Redis存储两类数据：一是登录图形验证码，设置5分钟有效期，超时自动失效；二是用户退出登录后的JWT Token黑名单，防止Token在有效期内被非法复用，从而有效保障系统的访问安全性。

## 2.6 Spring Security与JWT

Spring Security是Spring生态体系中专门用于处理安全认证与授权的框架，提供了完善的身份认证、权限管理和防攻击机制[11]。它通过一系列过滤器链对每个HTTP请求进行拦截，验证请求的合法性，并根据用户角色决定是否允许访问对应资源。

JWT（JSON Web Token）是一种基于JSON格式的开放标准，用于在各方之间安全地传输信息。JWT由Header（头部）、Payload（载荷）和Signature（签名）三部分组成，通过Base64编码后用"."连接。本系统将Spring Security与JWT结合使用，实现了无状态的用户认证机制：用户登录成功后服务器签发JWT Token，客户端在后续请求的Authorization头中携带Token，服务端通过验证Token的签名和有效期完成身份验证，无需在服务器端维护Session状态，有效提升了系统的可扩展性[11]。系统采用HS512签名算法，Token有效期为2小时。

## 2.7 开发工具与环境

IntelliJ IDEA是由JetBrains公司开发的Java集成开发环境，被业界公认为最优秀的Java开发工具之一。它提供了智能代码补全、实时代码分析、强大的重构支持和便捷的调试功能，内置对Spring Boot、Maven、Git等主流技术和工具的深度集成，极大地提高了开发效率。本系统后端开发使用IntelliJ IDEA完成代码编写、调试与项目管理工作。

前端开发使用Visual Studio Code作为编辑器，配合Vite构建工具提供极速的热模块替换（HMR）开发体验。Vite基于浏览器原生ES Module，在开发环境下无需打包即可启动，构建速度相比传统Webpack方案有显著提升，同时提供完善的代理配置，将前端开发服务器（端口3000）的API请求转发至后端服务（端口8080），实现前后端联调。

## 2.8 本章小结

本章详细介绍了社区物业管理系统开发所采用的核心技术。Spring Boot框架提供了高效稳定的后端开发基础；MyBatis-Plus简化了数据访问层的开发工作；Vue 3框架为前端界面提供了高效灵活的构建能力；MySQL 8.0承担了系统全部业务数据的存储与管理；Redis负责验证码和Token黑名单的缓存处理；Spring Security结合JWT实现了完善的安全认证机制；IntelliJ IDEA与Vite为开发过程提供了高效的工程化支撑。这些技术的综合运用，为后续系统的分析、设计与实现工作打下了坚实的技术基础。
